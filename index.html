Connect your Google Sheet

Paste the same LinkedIn “Ad Performance Report” export into a Google Sheet each time you have new numbers, publish that sheet to the web as CSV, and this page will pull it live on every visit. This connection is shared — once saved, everyone on the team sees the same live sheet, no per-browser setup needed.

  1. In Google Sheets: File → Import your latest export CSV (or paste over the existing data on a tab named e.g. Raw Export).
  2. File → Share → Publish to web → select the sheet/tab → format Comma-separated values (.csv) → Publish.
  3. Copy the link it gives you (looks like …/pub?output=csv) and paste it below.
